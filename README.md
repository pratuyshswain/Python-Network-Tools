# Python Network & Security Tools

A collection of cybersecurity scripts and network utilities built with Python. These tools demonstrate core concepts in network reconnaissance, cryptography, and input validation.

## 📂 Projects Included

### 1. Network Port Scanner (`port_scanner.py`)
A reconnaissance tool that uses Python's `socket` library to scan a target IP address for open TCP ports.
* **Features:** Scans a defined range of ports, identifies open connections, and handles socket timeouts.
* **Key Concept:** Socket Programming & TCP Handshakes.

### 2. Password Strength Analyzer (`password_strength.py`)
A security tool that evaluates the complexity of a user's password based on industry-standard policies.
* **Features:** Checks for length (8+ chars), uppercase/lowercase letters, numbers, and special characters using **Regular Expressions (Regex)**.
* **Key Concept:** Input Validation & Pattern Matching.

### 3. Text Encryption Tool (`encryption_tool.py`)
A cryptography script implementing the classic Caesar Cipher algorithm.
* **Features:** Encrypts and decrypts text by shifting ASCII characters; preserves non-alphabetic characters.
* **Key Concept:** Modular Arithmetic & Data Obfuscation.
